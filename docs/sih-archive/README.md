# SIH-era archive

These files are from the original DeadZone sprint for Smart India Hackathon 2026
(4 to 11 September 2026, Harshit Reddy Alla's team). They are kept for history
and for their hard-won troubleshooting notes. They are **not current**:

- They describe a Windows laptop with a native CouchDB service and a specific
  user folder (`START_ALL.ps1`, `DEMO_GUIDE.md`).
- Some describe transport (Nearby Connections, relays) that the code never had.
- The demo now starts with `pnpm demo` and is checked with `pnpm demo:check`.

Current documentation: [`../ARCHITECTURE.md`](../ARCHITECTURE.md),
[`../DEMO.md`](../DEMO.md), [`../THINK-TO-IMPACT.md`](../THINK-TO-IMPACT.md),
[`../decisions.md`](../decisions.md), [`../../CREDITS.md`](../../CREDITS.md).

Still useful here: `demo-runbook.md` ("If it breaks", and the two map-failure
signatures) and `demo-day-checklist.md` (phone setup, Android captive portal).
The weather AI warm-up procedure is in `demo-runbook.md` if `apps/ai` is ever
demoed.
